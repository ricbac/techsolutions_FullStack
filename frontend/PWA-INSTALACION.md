# Instalacion PWA de TechSolutions

TechSolutions puede instalarse como PWA desde el navegador. No es una app nativa de App Store o Play Store.

## iPhone o iPad desde Safari

1. Abre la URL del sistema en Safari.
2. Inicia sesion si es necesario.
3. Toca el boton Compartir de Safari.
4. Selecciona "Agregar a pantalla de inicio".
5. Confirma el nombre "TechSolutions" y toca "Agregar".

La app aparecera como icono en la pantalla de inicio. Para datos actualizados, el sistema requiere conexion a internet.

## Android desde Chrome

1. Abre la URL del sistema en Chrome.
2. Toca el menu de tres puntos.
3. Selecciona "Instalar app" o "Agregar a pantalla principal".
4. Confirma la instalacion.

## Notas

- La PWA permite abrir TechSolutions con apariencia de app.
- Las funciones principales consultan el backend, por lo que necesitan internet.
- Si no hay conexion, se mostrara una pantalla simple indicando que no se pueden cargar datos actualizados.
